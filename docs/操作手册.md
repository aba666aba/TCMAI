1. 软件简介
================================================================================

1.1 软件名称
    中医药智能问答系统

1.2 版本号
    v1.0.0

1.3 功能概述
    中医药智能问答系统是一款基于 AI 大模型的中医药领域智能问答应用。
    系统结合传统中医药知识库与现代人工智能技术，为用户提供：
    - 中医药知识查询
    - 症状分析
    - 方剂推荐
    - 功效搜索
    - 历史记录管理

1.4 技术特点
    - 基于 MiniMind2 MOE 大模型（1.45 亿参数）
    - SQLite 知识库（20+ 药材，15+ 方剂，15+ 症状）
    - Flask Web 框架
    - 响应式界面设计

2. 运行环境
================================================================================

2.1 硬件要求
    - CPU: 双核处理器及以上
    - 内存：4GB 及以上（推荐 8GB）
    - 硬盘：1GB 可用空间
    - 显卡：可选（支持 CUDA 可加速推理）

2.2 软件要求
    - 操作系统：Windows 10/11, Linux, macOS
    - Python: 3.8 及以上版本
    - 浏览器：Chrome, Firefox, Edge 等现代浏览器

3. 安装步骤
================================================================================

3.1 获取软件
    从项目仓库下载或克隆源代码到本地。

3.2 安装依赖
    打开命令行，进入项目目录，执行：
    
    pip install -r requirements.txt

3.3 可选：安装截图功能
    pip install mss pillow

3.4 验证安装
    python -c "import flask; print('Flask 版本:', flask.__version__)"

3.5 启动系统
    python src/main.py

3.6 访问系统
    打开浏览器，访问：http://localhost:5000

4.2 问答功能
    操作步骤：
    1. 在文本框中输入问题或症状描述
    2. 点击快捷症状标签（可选）
    3. 点击"提交查询"按钮
    4. 等待系统分析并显示回答

    示例问题：
    - "我最近感觉乏力、食欲不振，有什么调理建议？"
    - "黄芪有什么功效？"
    - "四君子汤适用于什么症状？"

4.3 历史记录功能
    访问路径：点击导航栏"历史记录"

    功能说明：
    - 搜索：在搜索框输入关键词，点击"搜索"
    - 查看详情：点击"查看详情"按钮，弹出详情窗口
    - 删除单条：点击"删除"按钮，确认后删除
    - 导出全部：点击"导出全部"按钮，导出为 JSON 文件
    - 清空历史：点击"清空历史"按钮，清空所有记录

4.4 配置管理（高级用户）
    配置文件位置：src/model/model_config.json

    可配置项：
    - hidden_size: 模型隐藏层维度（640）
    - num_hidden_layers: Transformer 层数（8）
    - use_moe: 是否启用 MOE（true）
    - temperature: 生成温度（0.7）
    - device: 推理设备（cpu/cuda）

6. 常见问题
================================================================================

6.1 启动失败
    Q: 提示"模块未正确加载"
    A: 检查模型文件是否存在：src/model/full_sft_640_moe.pth

6.2 数据库连接失败
    Q: 提示"知识库连接失败"
    A: 检查数据库文件是否存在：data/tcm_knowledge.db
       如不存在，运行：sqlite3 data/tcm_knowledge.db < data/create_tcm_db.sql

6.3 端口被占用
    Q: 提示"Address already in use"
    A: 修改启动命令：python src/main.py --port 5001
       或关闭占用 5000 端口的程序

6.4 模型推理慢
    Q: 回答生成速度慢
    A: 1. 使用 CUDA 加速（需要 NVIDIA 显卡）
       2. 减小 max_length 参数
       3. 使用更小的模型

7. 注意事项
================================================================================

7.1 合规提示
    - 本系统仅提供中医药知识科普，不构成医疗建议
    - 回答内容仅供参考，具体用药请咨询专业医师
    - 如有健康问题，请及时就医

7.2 使用限制
    - 单次输入不超过 500 字
    - 不包含敏感词汇（如"治愈"、"根治"等）
    - 不用于诊断目的

7.3 数据隐私
    - 查询记录保存在本地
    - 可随时清空历史记录
    - 不收集用户身份信息

7.4 备份建议
    - 定期备份 data/history.json（历史记录）
    - 备份 data/tcm_knowledge.db（知识库）
