# 降级方案说明文档

## 概述

当 AI 模型权重文件损坏或与当前模型架构不兼容时，系统会自动切换到降级方案，使用基于规则的中医药知识提供回答，确保应用始终能提供有用的服务。

## 问题背景

模型输出出现以下问题时说明权重文件有问题：
- **Greedy decoding** 产生重复字符（如"啊啊啊啊啊"）
- **Sampling** 产生乱码字符

这说明模型权重可能损坏或与当前模型架构不兼容。

## 降级方案架构

### 文件结构

```
src/
├── service/
│   └── fallback.py          # 降级回答模块（新增）
├── model/
│   └── infer.py             # 模型推理模块（已修改）
└── frontend/
    └── main.py              # 前端入口（已修改）
```

### 核心组件

#### 1. `fallback.py` - 降级回答模块

**主要功能**：
- `TCM_KNOWLEDGE`：内置中医药知识库（15 种常用药材、14 个经典方剂、15 个常见症状）
- `SYNDROMES`：常见证型及治法
- `detect_symptoms()`：从用户问题中检测症状
- `search_herbs()` / `search_formulas()`：搜索药材和方剂
- `generate_fallback_answer()`：生成降级回答
- `is_model_output_valid()`：检查模型输出是否有效

**内置知识库**：
- **药材**：人参、黄芪、白术、甘草、当归、熟地黄、茯苓、陈皮、柴胡、黄芩、黄连、生姜、大枣、桂枝、白芍
- **方剂**：四君子汤、四物汤、八珍汤、补中益气汤、归脾汤、六味地黄丸、逍遥散、小柴胡汤、桂枝汤、银翘散、藿香正气散、龙胆泻肝汤、温胆汤、生脉散
- **症状**：乏力、食欲不振、失眠、头痛、咳嗽、腹痛、腹泻、便秘、心悸、头晕、发热、恶寒、胁痛、自汗、恶心呕吐

#### 2. `infer.py` - 模型推理模块

**修改内容**：
- 添加 `model_available` 标志，标记模型是否可用
- 添加 `_is_output_valid()` 方法，检查模型输出质量
- `infer()` 方法在模型不可用或输出无效时返回 `None`，触发降级方案

**输出验证规则**：
- 检查空输出
- 检查连续重复字符（如"啊啊啊啊啊"）
- 检查重复片段（如"ABCABCABC"）
- 检查乱码字符（控制字符）
- 检查是否包含有效汉字

#### 3. `frontend/main.py` - 前端入口

**修改内容**：
- 导入 `generate_fallback_answer` 函数
- 在 `/api/query` 接口中，当模型返回 `None` 时自动调用降级方案
- 返回 `mode` 字段标识回答来源（`ai` 或 `fallback`）
- 即使出错也尝试使用降级方案，确保用户总能获得回答

## 工作流程

```
用户提问
    │
    ▼
模型推理 (infer.py)
    │
    ├─ 成功且输出有效 ──► AI 回答 (mode: ai)
    │
    ├─ 模型加载失败 ──┐
    │                 │
    ├─ 输出重复字符 ──┼──► 降级方案 (fallback.py) ──► 基于规则的回答 (mode: fallback)
    │                 │
    ├─ 输出乱码 ──────┘
    │
    └─ 其他错误 ──────┘
```

## 使用示例

### API 调用

```python
import requests

response = requests.post('http://localhost:5000/api/query', json={
    'query': '我最近感觉乏力，食欲不振，有什么调理建议？',
    'symptoms': ['乏力', '食欲不振']
})

result = response.json()
print(f"回答模式：{result['mode']}")  # ai 或 fallback
print(f"回答内容：{result['answer']}")
print(f"免责声明：{result['disclaimer']}")
```

## 优势与局限

### 优势
- ✅ **始终可用**：不依赖外部模型文件
- ✅ **响应快速**：基于规则匹配，无需推理
- ✅ **结果可控**：输出内容经过审核，无乱码风险
- ✅ **知识准确**：内置经典中医药知识
- ✅ **自动切换**：无需用户干预

### 局限
- ⚠️ **知识范围有限**：仅包含内置的常用药材和方剂
- ⚠️ **灵活性较低**：无法处理复杂或罕见问题
- ⚠️ **无上下文理解**：不支持多轮对话
- ⚠️ **回答模板化**：缺乏个性化

## 故障排查

### 问题 1：降级方案未触发

**检查**：
1. 查看日志中是否有 "AI 模型不可用" 或 "使用降级方案" 的提示
2. 检查 API 响应中的 `mode` 字段是否为 `fallback`

**解决**：
- 确认 `infer.py` 中的 `model_available` 标志正确设置
- 确认 `frontend/main.py` 中导入了 `generate_fallback_answer`

### 问题 2：降级方案回答不准确

**检查**：
1. 查看症状是否正确检测
2. 查看知识库中是否有相关数据

**解决**：
- 在 `fallback.py` 中添加更多症状关键词映射
- 扩展 `TCM_KNOWLEDGE` 中的知识库内容

### 问题 3：模型输出被误判为无效

**调整**：
- 修改 `_is_output_valid()` 方法中的验证规则
- 调整重复字符检测的阈值

## 总结

降级方案确保中医药智能问答系统在模型权重文件损坏或不可用时，仍能提供基于规则的中医药知识回答，保证系统的基本功能始终可用。当模型恢复正常时，系统会自动切换回 AI 推理模式，无需人工干预。
