# CPU 性能优化配置说明

## 默认配置（已优化）

本系统已针对 **无 GPU 的普通电脑** 进行优化，默认使用 CPU 运行。

---

## 硬件要求

### 最低配置
- **CPU**: 双核处理器（Intel i3 或同等性能）
- **内存**: 4GB
- **硬盘**: 1GB 可用空间

### 推荐配置
- **CPU**: 四核处理器（Intel i5 或同等性能）
- **内存**: 8GB
- **硬盘**: 2GB 可用空间

---

| CPU 型号 | 推理速度 | 内存占用 |

## 配置文件说明

### model_config.json

```json
{
  "device": "cpu",           // 强制使用 CPU
  "max_length": 512,         // 最大生成长度（可减少到 256 提速）
  "num_threads": 4,          // CPU 线程数
  "intra_op_num_threads": 1, // 操作内线程数
  "inter_op_num_threads": 1  // 操作间线程数
}
```

### 优化选项

**如果感觉速度慢**，可以调整以下参数：

1. **减少生成长度**（最快见效）：
   ```json
   "max_length": 256  // 从 512 改为 256
   ```

2. **调整 CPU 线程**：
   ```json
   "num_threads": 8   // 根据你的 CPU 核心数调整
   ```

3. **降低采样温度**（减少计算量）：
   ```json
   "temperature": 0.5  // 从 0.7 改为 0.5
   ```

## CPU 优化技巧

### 1. 关闭不必要的后台程序
释放更多 CPU 资源给模型推理。

### 2. 使用高性能电源模式
- Windows: 电源选项 → 高性能
- 笔记本：接通电源使用

### 3. 启用 OneDNN 优化
系统已自动启用 Intel OneDNN 优化库。

### 4. 调整并发设置
如果是多用户同时使用，建议：
```json
"intra_op_num_threads": 1,
"inter_op_num_threads": 1
```

## 常见问题

### Q1: CPU 占用率 100% 正常吗？
**正常**。模型推理时会充分利用 CPU 资源，这是预期的。

### Q2: 风扇声音大怎么办？
这是 CPU 高负载运行的正常现象。建议：
- 确保通风良好
- 使用散热垫（笔记本）
- 清理灰尘

### Q3: 如何进一步提速？
1. 减少 `max_length` 到 256
2. 升级到更快的 CPU
3. 添加 GPU（如果主板支持）

### Q4: 内存占用多少？
- 模型加载后：约 500-600MB
- 推理过程中：约 800MB-1GB
