1. 引言
================================================================================

1.1 软件简介

中医药智能问答系统（TCMAI）是一款基于 Python tkinter 框架开发的桌面应用
程序，旨在为用户提供中医药领域的智能问答与知识推荐服务。

系统内置 33 种常见症状知识库，9 种中医证型辨证规则，超过 3000 种药材和
1000 种方剂的数据库，支持自然语言症状输入和基于深度学习的智能推荐。

软件提供两种运行模式：
（1）快速模式：基于规则引擎的本地问答，无需额外依赖
（2）AI 模式：基于 TCMNet Transformer 深度学习模型的智能推荐

1.2 主要功能

（1）症状输入与分析：支持自然语言描述和快捷标签选择
（2）智能辨证：根据症状组合推断中医证型
（3）方剂推荐：推荐匹配的经典方剂
（4）药材推荐：推荐对症的单味药材
（5）安全校验：检测配伍禁忌和毒性药材
（6）养生建议：根据症状生成针对性调理建议
（7）历史记录：保存、查看、搜索、导出和删除历史记录

1.3 运行环境

硬件要求：
  - CPU：双核处理器及以上
  - 内存：4GB 及以上（推荐 8GB）
  - 硬盘：500MB 可用空间
  - 显卡：可选（NVIDIA GPU 可加速 AI 模式推理）
  - 显示器：分辨率 1280x720 及以上

软件要求：
  - 操作系统：Windows 10/11（64 位）
  - Python：3.9 及以上版本
  - 可选依赖：PyTorch（AI 模式需要）

2. 软件安装
================================================================================

2.1 获取软件

从项目仓库下载完整源代码到本地。项目目录结构如下：

  tcmai/
  ├── launcher.py              # 桌面启动器（入口文件）
  ├── launcher.pyw             # 无控制台窗口启动器
  ├── pyproject.toml           # 项目配置文件
  ├── requirements.txt         # 基础依赖清单
  ├── requirements-recommender.txt  # AI 模式依赖清单
  ├── tcm_desktop.spec         # PyInstaller 打包配置
  ├── 快速启动.bat             # 快速启动脚本
  ├── 打包桌面版.bat           # 桌面版打包脚本
  ├── src/
  │   ├── main.py              # 命令行入口
  │   ├── core/                # 核心业务逻辑模块
  │   │   ├── __init__.py
  │   │   ├── tcm_config.py    # 统一配置中心
  │   │   ├── symptom_pipeline.py  # 症状处理管线
  │   │   ├── symptom_analysis.py  # 症状分析器
  │   │   ├── fallback.py      # 降级回答引擎
  │   │   ├── knowledge_base.py    # 知识库查询
  │   │   ├── result_verify.py # 结果校验
  │   │   └── data_desensitize.py  # 数据脱敏
  │   └── desktop/
  │       ├── __init__.py
  │       ├── app.py           # 桌面主界面
  │       └── service.py       # 桌面业务服务
  ├── tcm_recommender/         # 深度学习推荐模块
  │   ├── __init__.py
  │   ├── model.py             # TCMNet 模型定义
  │   ├── train.py             # 训练脚本
  │   ├── recommend.py         # 推理接口
  │   ├── data_pipeline.py     # 数据生成管线
  │   └── data_expansion.py    # 数据库扩展
  ├── data/
  │   ├── tcm_knowledge.db     # SQLite 知识库
  │   └── train_data.npz       # 训练数据
  └── docs/                    # 文档目录

2.2 安装 Python 运行环境

本软件需要 Python 3.9 及以上版本。若尚未安装：

（1）访问 Python 官方网站 https://www.python.org/downloads/
（2）下载 Python 3.9 或更高版本的 Windows 安装包
（3）安装时勾选"Add Python to PATH"选项
（4）完成安装后，打开命令行验证安装：
    python --version

2.3 安装依赖包

打开命令行（cmd），进入项目目录：

（1）安装基础依赖：
    pip install -r requirements.txt

（2）如需使用 AI 深度学习推荐模式，额外安装：
    pip install -r requirements-recommender.txt

（3）如需 GPU 加速（NVIDIA 显卡），安装 CUDA 版 PyTorch：
    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124

2.4 启动软件

启动方式一：直接双击快速启动脚本
  双击项目目录中的"快速启动.bat"文件即可启动软件。

启动方式二：命令行启动
  打开命令行，进入项目目录，执行：
  python launcher.py

启动方式三：无控制台窗口启动
  双击 launcher.pyw 文件，启动时不显示命令行窗口。

启动后，系统将显示主窗口界面。若 AI 模式所需依赖未安装，
或模型文件不存在，系统将自动使用快速模式运行。

4.1 症状输入

用户可以通过两种方式输入症状：

方式一：直接输入文字
  （1）在左侧面板的文本输入框中，直接输入症状描述
  （2）例如："我最近感觉乏力、食欲不振，还失眠"
  （3）输入内容限制：1-1000 个字符
  （4）系统会自动从文字中识别症状关键词

方式二：使用快捷标签
  （1）在左侧面板的"快捷症状"区域，点击症状按钮
  （2）点击后该症状名称会自动追加到输入框中
  （3）支持同时选择多个症状
  （4）可结合文字输入和标签选择混合使用

4.2 快捷症状标签

软件提供 15 个常见症状快捷按钮：

  乏力、食欲不振、失眠、头痛、咳嗽、
  腹痛、腹泻、便秘、心悸、头晕、
  发热、畏寒、恶心、腰膝酸软、口干

每个按钮在鼠标悬停时颜色会变化，点击后该症状名称
会添加到输入框末尾。

4.3 智能问答

操作步骤：
  （1）输入症状描述（文字输入或点击快捷标签）
  （2）点击"提交查询"按钮
  （3）系统状态栏显示"正在分析您的问题，请稍候..."
  （4）进度条开始转动
  （5）等待系统处理

系统处理流程：
  （1）症状检测：从输入文本中识别症状关键词
  （2）AI 推理（AI 模式）：调用深度学习模型进行辨证和推荐
  （3）结果生成：格式化输出辨证结果、推荐方案和安全提示
  （4）快速模式（备选）：基于规则引擎生成回答

5. 运行模式说明
================================================================================

5.1 快速模式（规则引擎）

运行条件：无需深度学习依赖，开机即用
核心引擎：基于中医辨证规则的 fallback 模块
数据来源：内置知识库（33 种症状、9 种证型、15 味药材、14 首方剂）
处理流程：症状检测 -> 知识库匹配 -> 证型推断 -> 回答生成
适用场景：轻量快速查询，不依赖外部模型

快速模式回答包含：
  症状分析、推荐方剂、相关知识、养生建议、免责提示

5.2 AI 模式（深度学习）

运行条件：需要安装 PyTorch 和模型文件
核心引擎：TCMNet Transformer 模型（11,192,726 参数）
数据来源：SQLite 数据库（3497 种药材、1019 种方剂、200 种症状）
处理流程：症状编码 -> 证型分类 -> 交叉注意力排序 -> 安全校验
适用场景：需要深度辨证和精准推荐的场景
加速支持：支持 NVIDIA CUDA GPU 加速推理

AI 模式回答包含：
  症状分析、推荐方剂（含组成和功效）、推荐药材（含功效）、
  安全提示（毒性药材检测+配伍禁忌检查）、针对性养生建议

5.3 模式切换机制

系统默认优先使用 AI 模式：
  （1）启动时检测 PyTorch 和模型文件是否可用
  （2）如果可用，使用 AI 模式进行推理
  （3）如果 AI 模式超时（60秒）或出错，自动重试一次
  （4）重试仍失败时，降级到快速模式
  （5）整个切换过程对用户透明

6. 注意事项
================================================================================

6.1 合规声明

  （1）本系统仅提供中医药知识科普和参考信息
  （2）不构成医疗诊断或治疗建议
  （3）所有回答均标注免责声明
  （4）如需健康问题，请咨询专业医疗机构或执业医师

6.2 使用限制

  （1）单次输入不超过 1000 个字符
  （2）单次症状列表不超过 20 项
  （3）系统不提供诊断功能
  （4）回答内容仅供参考，不具备临床指导意义

6.3 数据隐私

  （1）所有查询记录保存在本地 JSON 文件
  （2）用户输入经过脱敏处理
  （3）可随时清空所有历史记录
  （4）系统不收集用户身份信息
  （5）日志文件按 5MB 大小轮转，保留 3 个备份

7. 常见问题
================================================================================

Q1：软件启动后界面没有显示？
A1：检查是否被任务栏遮挡；确认显示器分辨率为 1280x720 或以上。

Q2：点击提交后长时间无响应？
A2：AI 模式首次加载模型需要一定时间，请耐心等待。如果超过 60 秒，
     系统会自动切换到快速模式。

Q3：如何判断当前使用的是快速模式还是 AI 模式？
A3：查看回答内容，AI 模式会包含更详细的方剂组成和置信度评分。也可
     查看历史记录中的"模式"字段。

Q4：为什么有些症状无法识别？
A4：系统内置 33 种常见症状词库和口语别名映射，若未匹配到可尝试
     使用更标准的症状名称。

Q5：如何关闭软件？
A5：点击窗口右上角的关闭按钮，或按 Alt+F4。

Q6：如何打包成独立的 exe 文件？
A6：双击"打包桌面版.bat"脚本，或运行 pyinstaller tcm_desktop.spec。

Q7：AI 模式提示模型不可用？
A7：检查 tcm_recommender/best_model.pth 文件是否存在，以及
     PyTorch 是否正确安装。
