# 中医药智能问答系统 - 可移动应用说明

## 📦 使用说明

本系统设计为**可移动应用**，可部署在优盘中，在任何 Windows 电脑上运行。

### 目录结构

```
TCMAI/                    ← 优盘根目录或任意位置
├── 启动系统.bat          ← 双击此文件启动
├── src/                  ← 源代码
├── models/               ← AI 模型权重
├── data/                 ← 数据资源
├── docs/                 ← 文档
└── requirements.txt      ← Python 依赖
```

---

## 🚀 快速启动

### 方式 1：双击启动（推荐）

1. 打开优盘中的 `TCMAI` 文件夹
2. 双击 **`启动系统.bat`**
3. 等待服务器启动（首次启动需要 20-40 秒加载 AI 模型）
4. 浏览器自动打开 http://localhost:5000

### 方式 2：命令行启动

```bash
# 打开命令提示符，进入 TCMAI 目录
cd X:\TCMAI  # X 为优盘盘符

# 启动系统
python src\main.py
```

- **操作系统**: Windows 7/10/11
- **Python**: 3.8+
- **内存**: 4GB

- **Python**: 3.9+

## 📋 使用前准备

### 1. 安装 Python

如果目标电脑未安装 Python：
1. 下载 Python 3.9+：https://www.python.org/downloads/
2. 安装时勾选 **"Add Python to PATH"**

### 2. 安装依赖

首次运行前，在 TCMAI 目录下执行：
```bash
pip install -r requirements.txt
```

或使用启动脚本自动安装。

## 🔧 常见问题

### Q1: 启动后浏览器显示"无法访问"
**A**: 等待 30-60 秒，AI 模型需要时间加载。查看服务器窗口的日志进度。

### Q2: 提示"端口 5000 被占用"
**A**: 关闭其他占用 5000 端口的程序，或修改 `src/main.py` 中的端口号。

### Q3: 模型加载失败
**A**: 检查 `models/` 目录下是否有 `full_sft_640_moe.pth` 文件。

### Q4: 在不同电脑上无法运行
**A**: 本系统使用相对路径，应可在任何 Windows 电脑运行。确保：
- Python 已安装并添加到 PATH
- 依赖包已安装
- 防火墙允许 5000 端口

## 📊 性能说明

### 启动时间
- **快速模式**（无 AI 模型）：约 3-5 秒
- **AI 模式**（完整模型）：约 20-40 秒（首次）

### 回答速度
- **快速模式**：< 1 秒
- **AI 模式**：5-15 秒（取决于 CPU）

### 资源占用
- **内存**: 约 600MB
- **CPU**: 推理时 30-50%

## 🛡️ 数据安全

- 所有数据存储在优盘本地
- 历史记录保存在 `data/history.json`
- 日志保存在 `data/logs/`
- 不会上传任何数据到云端

---

## 📝 更新说明

如需更新系统：
1. 备份 `data/` 目录（保留历史记录）
2. 复制新的代码文件到优盘
3. 重新启动即可
