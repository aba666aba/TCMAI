# 快速启动指南

## 🚀 一键启动

双击运行 **`启动系统.bat`** 文件即可自动启动系统并打开浏览器。

### 启动流程

```
启动系统.bat
    │
    ├─→ 检查 Python 环境
    │
    ├─→ 检查依赖包（自动安装缺失的依赖）
    │
    ├─→ 启动服务器
    │
    └─→ 自动打开浏览器（http://localhost:5000）
```

---

## 📝 使用说明

### 1. 启动系统

**方式一：双击启动（推荐）**
```
双击：启动系统.bat
```

**方式二：命令行启动**
```bash
cd E:\Tom\中医药智能问答系统
python src/main.py
```

然后访问：http://localhost:5000

### 2. 使用功能

- **智能问答**：在输入框输入问题或选择症状标签
- **历史记录**：点击导航栏查看历史查询记录
- **导出结果**：支持导出查询结果

### 3. 停止系统

关闭命令行窗口或按 `Ctrl+C`

## 🔧 故障排查

### 问题 1：双击无法启动

**原因**：未安装 Python 或环境变量未配置

**解决**：
1. 下载安装 Python 3.8+：https://www.python.org/downloads/
2. 安装时勾选 "Add Python to PATH"

### 问题 2：依赖包缺失

**解决**：
```bash
pip install -r requirements.txt
```

### 问题 3：端口被占用

**解决**：
1. 关闭其他占用 5000 端口的程序
2. 或修改 `src/frontend/main.py` 中的端口号
