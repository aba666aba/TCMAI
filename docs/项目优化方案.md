## 三、代码优化

### 3.1 入口文件合并

**问题**: `launcher.py` 与 `src/main.py` 存在代码重复（环境变量设置、日志配置、控制台隐藏），两份文件功能几乎完全一致。

**方案**: 
- `launcher.py` 作为唯一入口，`src/main.py` 改为仅导出核心函数
- 或删除 `src/main.py`，统一使用 `launcher.py`/`launcher.pyw`

```python
# 优化后 launcher.py — 单一入口
def setup_environment():
    """设置项目环境变量和路径"""
    root = os.path.dirname(os.path.abspath(__file__))
    os.environ.setdefault("TCMAI_ROOT", root)
    if hasattr(sys, '_MEIPASS'):
        sys.path.insert(0, os.path.join(sys._MEIPASS, '_internal', 'src'))
    else:
        sys.path.insert(0, root)

def configure_logging():
    """配置日志系统"""
    # ...

def main():
    setup_environment()
    configure_logging()
    from src.desktop.app import run_desktop_app
    run_desktop_app()
```

## 五、依赖管理

### 5.1 现有依赖文件

| 文件 | 内容 | 处理 |
|------|------|------|
| `requirements.txt` | pytest, ruff | 保留（开发依赖） |
| `requirements-recommender.txt` | torch, numpy, tqdm | 保留（推理依赖） |
| `tcm_recommender/requirements.txt` | torch, numpy, tqdm（重复） | 删除 |

### 5.2 优化建议

在 `pyproject.toml` 中增加 optional-dependencies 分组：

```toml
[project.optional-dependencies]
recommender = [
    "torch>=2.0.0",
    "numpy>=1.24.0",
    "tqdm>=4.65.0",
]
dev = [
    "pytest>=7.0.0",
    "ruff>=0.8.0",
]
```

安装方式：
```bash
pip install -e .              # 仅核心
pip install -e .[recommender] # 含深度学习
pip install -e .[dev]         # 含开发工具
```
