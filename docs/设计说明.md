# 中医药智能问答系统 - 设计说明

## 一、系统概述

### 1.1 设计目标

本系统旨在构建一个智能化、专业化的中医药问答平台，通过 AI 大模型技术结合传统中医药知识库，为用户提供准确、可靠的中医药知识查询服务。

### 1.2 设计原则

- **专业性**：确保中医药知识的准确性和权威性
- **易用性**：简洁直观的界面设计，降低使用门槛
- **安全性**：用户数据脱敏处理，保护隐私
- **合规性**：明确标注非医疗建议，规避法律风险

#### 2.2.2 症状分析模块 (symptom_analysis.py)

**设计思路**：
- 基于中医辨证论治理论
- 实现症状组合分析与证型判断
- 提供禁忌校验功能

**分析流程**：
```
用户输入症状 → 症状标准化 → 证型判断 → 禁忌检查 → 输出分析结果
                              ↓
                        症状详情查询（已实现）
```

**核心功能**：
- `analyze()`: 症状综合分析
- `get_symptom_info()`: 从数据库查询症状详情（已实现）
- `_get_basic_symptom_info()`: 备选方案（数据库不可用时）

#### 2.2.3 结果校验模块 (result_verify.py)

**设计思路**：
- 对 AI 生成的回答进行溯源
- 自动添加合规提示
- 检测并过滤不当内容

#### 2.2.4 数据脱敏模块 (data_desensitize.py)

**设计思路**：
- 识别并脱敏用户个人信息
- 日志数据匿名化处理
- 符合数据安全规范

## 三、数据库设计

提供 RESTful API，支持：

| 接口 | 方法 | 说明 | 状态 |

| `/api/query` | POST | 提交问答请求 | ✅ 已实现 |
| `/api/history` | GET | 获取历史记录 | ✅ 已实现 |
| `/api/history/<id>` | DELETE | 删除单条历史 | ✅ 已实现 |

**历史记录功能**：
- 支持搜索（按关键词过滤）

## 八、总结
