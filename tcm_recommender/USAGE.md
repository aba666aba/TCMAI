# 中医药智能推荐系统 - 使用指南

## 📋 系统功能

本系统是一个深度学习模型，可根据患者症状推荐中药材和方剂，供专业中医师参考。

### 核心功能

1. **症状分析** - 支持多症状组合输入
2. **药材推荐** - 从 1,010 种药材中推荐
3. **方剂推荐** - 从 347 个方剂中推荐
4. **安全校验** - 自动检查配伍禁忌（十八反、十九畏）
5. **毒性警示** - 标注有毒药材

---

## 🚀 快速开始

### 1. 安装依赖

```bash
cd E:\Tom\TCMAI\tcm_recommender
pip install -r requirements.txt
```

### 2. 训练模型

```bash
# 训练模型（约 5-10 分钟）
python train.py --epochs 50 --batch-size 32
```

训练完成后会生成：
- `best_model.pth` - 最佳模型权重
- `best_model_history.json` - 训练历史

### 3. 使用推荐

```bash
# 命令行使用
python recommend.py "乏力 食欲不振 失眠"

# 输出 JSON 格式
python recommend.py "乏力 食欲不振" --json

# 指定返回数量
python recommend.py "头痛 发热" --top-herb 15 --top-formula 10
```

## ⚠️ 安全校验规则

### 十八反

- 甘草反大戟、芫花、甘遂

生川乌、生草乌、附子、巴豆、甘遂、大戟、芫花等

## 🔧 模型架构

```
症状输入 (max 20 个)
    ↓
症状编码器 (Embedding + Attention)
    ↓
症状向量 (64 维)
    ↓
    ├─→ 药材推荐器 → 1010 个药材分数
    └─→ 方剂推荐器 → 347 个方剂分数
    ↓
Top-K 选择
    ↓
安全校验
    ↓
输出结果
```

### 模型参数

- 总参数量：~500K
- 训练时间：5-10 分钟 (CPU)
- 推理时间：<0.1 秒
- 内存占用：~50MB

## 💡 使用建议

### 给中医师的建议

1. **参考而非依赖** - 模型推荐仅供参考，请结合临床经验判断
2. **注意安全检查** - 系统会自动检查配伍禁忌，但医师应做最终判断
3. **辨证施治** - 同样症状可能对应不同证型，需个体化治疗
4. **注意剂量** - 系统不推荐剂量，需医师根据情况决定

### 适用场景

- ✅ 中医诊所辅助诊断
- ✅ 中医药教学参考
- ✅ 中医药研究
- ✅ 个人学习参考

### 不适用场景

- ❌ 自我诊断和自我治疗
- ❌ 替代专业中医师
- ❌ 急诊重症
- ❌ 孕妇和儿童用药
