## 📊 系统概述

这是一个**深度学习推荐系统**，专门用于根据症状推荐中药材和方剂。

### 核心特点

1. **不是对话 AI** - 不生成语言，只输出结构化推荐结果
2. **专业参考工具** - 供中医师参考，医师自行判断
3. **安全校验** - 自动检查配伍禁忌、毒性药材
4. **快速推理** - <0.1 秒完成推荐

---

## 🏗️ 系统架构

```
输入：症状列表
  ↓
[症状编码器] - Embedding + Attention
  ↓
[症状向量] - 64 维特征
  ↓
  ├─→ [药材推荐器] → 1,010 个药材分数
  └─→ [方剂推荐器] → 347 个方剂分数
  ↓
[Top-K 选择] - 选择前 N 个推荐
  ↓
[安全校验] - 检查配伍禁忌、毒性
  ↓
输出：结构化推荐结果
```

### 模型参数

| 组件 | 参数量 |
|------|--------|

| 药材推荐器 | ~100K |
| 方剂推荐器 | ~10K |

## 🎯 功能说明

### 1. 数据加载 (data_loader.py)

- 从数据库加载 1,010 种药材
- 加载 347 个方剂
- 定义 31 种常见症状
- 内置配伍禁忌规则（十八反、十九畏、孕妇禁用）

### 2. 模型架构 (model.py)

**SymptomEncoder** - 症状编码器
- Embedding 层：症状 ID → 64 维向量
- Multi-Head Attention：捕捉症状间关系
- LayerNorm + Residual：稳定训练

**HerbRecommender** - 药材推荐器
- 3 层全连接网络
- 输出：1,010 个药材的推荐分数

**FormulaRecommender** - 方剂推荐器
- 2 层全连接网络
- 输出：347 个方剂的推荐分数

**SafetyChecker** - 安全校验器
- 检查十八反、十九畏
- 检查孕妇禁用
- 检查毒性药材

### 3. 训练脚本 (train.py)

- 支持 CPU/CUDA 训练
- 自动验证和早停
- 保存最佳模型
- 训练历史可视化

### 4. 推理脚本 (recommend.py)

- 命令行交互
- 支持 JSON 输出
- 格式化文本输出
- 实时安全校验

## 🚀 使用流程

### 1. 安装依赖

```bash
cd E:\Tom\TCMAI\tcm_recommender
pip install torch numpy tqdm
```

### 2. 训练模型

```bash
python train.py --epochs 50 --batch-size 32
```

**训练时间**:
- CPU: 约 5-10 分钟
- GPU: 约 1-2 分钟

**输出**:
- `best_model.pth` - 最佳模型权重
- `best_model_history.json` - 训练指标

### 3. 使用推荐

```bash
# 基本使用
python recommend.py "乏力 食欲不振 失眠"

# JSON 输出
python recommend.py "头痛 发热" --json

# 指定数量
python recommend.py "腹痛 腹泻" --top-herb 15 --top-formula 10
```

## 🔧 技术细节

### 损失函数

```python
# 药材推荐：交叉熵损失
herb_loss = CrossEntropyLoss()

# 方剂推荐：交叉熵损失
formula_loss = CrossEntropyLoss()

# 总损失
total_loss = herb_loss + formula_loss
```

### 优化器

```python
AdamW(
    lr=0.001,
    weight_decay=1e-5
)
```

### 学习率调度

```python
ReduceLROnPlateau(
    factor=0.5,
    patience=3
)
```

### 早停策略

```python
early_stop_patience = 10  # 10 个 epoch 无改进则停止
```
