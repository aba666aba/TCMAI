# 中医药智能推荐系统 - 模型训练

**版本**: v1.0  
**日期**: 2026 年 3 月 23 日

## 系统架构

```
症状编码 → 神经网络 → 药材评分 → Top-K 推荐 → 安全校验 → 输出
           ↓
      注意力机制
           ↓
      配伍禁忌检查
```

## 功能特点

1. **多症状输入** - 支持多个症状组合
2. **药材推荐** - 从 1000+ 药材中推荐
3. **方剂推荐** - 推荐完整方剂
4. **安全校验** - 检查配伍禁忌（十八反、十九畏）
5. **毒性警示** - 标注有毒药材

## 训练数据

- 药材数据：1,010 条
- 方剂数据：347 条
- 症状 - 药材映射：从数据库提取
- 配伍禁忌：内置规则

## 模型配置

- 输入维度：症状数量 (max 20)
- 隐藏层：256 → 128 → 64
- 输出维度：药材数量 (1010)
- 激活函数：ReLU + Sigmoid
- 损失函数：BCEWithLogitsLoss

## 使用方法

```bash
# 训练模型
python train_model.py

# 使用模型推荐
python recommend.py "乏力 食欲不振 失眠"
```
