# 中医药智能问答系统

## 系统简介

中医药智能问答系统是一款基于 AI 大模型的中医药领域智能问答应用。系统结合传统中医药知识库与现代人工智能技术，为用户提供中医药知识查询、症状分析、方剂推荐等服务。

**版本**：v2.0.0
**更新日期**：2026 年 3 月
**模式**：基于知识库的快速模式（1,641 条中医药数据）

## 主要功能

- **智能问答**：基于中医药知识库，提供专业准确的回答
- **知识库查询**：整合中医药典籍、方剂、药材等专业知识（1,010+ 药材，347+ 方剂，63+ 中成药，221+ 民间验方）
- **症状分析**：根据用户描述的症状组合进行辨证分析
- **方剂推荐**：基于症状匹配推荐合适的中药方剂
- **功效搜索**：支持按功效关键词搜索药材和方剂
- **历史记录**：保存用户查询历史，支持搜索、查看详情、删除
- **配置管理**：支持 JSON 配置文件加载和保存
- **截图功能**：支持屏幕截图（需安装 mss 或 Pillow）
- **合规提示**：自动添加非医疗建议声明

## 快速开始

### 环境要求

- **Python 3.8+**
- **操作系统**: Windows/Linux/MacOS
- **内存**: 2GB+（无需 GPU）
- **GPU**: **不需要**！系统使用基于知识库的快速模式

### 安装步骤

1. 克隆或下载本项目
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

   > **注意**: 系统已移除 AI 模型依赖，只需安装 Flask 即可

3. 启动系统：
   ```bash
   python src/main.py
   ```
4. 访问 http://localhost:5000

### 性能说明

**快速模式性能**：
- 响应速度：<1 秒/回答
- 内存占用：约 200MB
- 适用：所有电脑（包括低配置）

**硬件要求**：
- 最低：单核 CPU + 2GB 内存
- 推荐：双核 CPU + 4GB 内存

**注意**：本系统使用基于知识库的快速模式，提供准确可靠的中医药知识回答。如需 AI 大模型能力，可自行接入外部 API（如 Qwen、ChatGLM 等）。

### 配置文件（可选）

系统使用基于知识库的快速模式，无需配置文件。

### Docker 部署

```bash
cd deploy
docker-compose up -d
```

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/query` | POST | 提交问答请求 |
| `/api/history` | GET | 获取历史记录 |
| `/api/history/<id>` | DELETE | 删除单条历史 |
| `/api/history` | DELETE | 清空所有历史 |
| `/api/export` | POST | 导出查询结果 |
